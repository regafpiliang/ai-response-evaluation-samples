# AI Response Evaluation Samples

This repository contains practical AI response evaluation exercises created for learning and portfolio purposes.

The samples demonstrate how I review AI-generated responses using structured criteria such as:

- Factual accuracy
- Instruction following
- Relevance
- Clarity
- Completeness
- Writing quality
- Cultural appropriateness
- Indonesian language naturalness

## Purpose

I am building practical experience in human-in-the-loop AI workflows, including AI training, response evaluation, data annotation, quality review, and research-based tasks.

All examples in this repository are original practice exercises and do not contain confidential assessment materials or proprietary platform data.

## Evaluation Framework

Each sample generally follows this structure:

1. User prompt
2. AI Response A
3. AI Response B
4. Evaluation criteria
5. Comparison
6. Preferred response
7. Reasoning
8. Suggested improvement
