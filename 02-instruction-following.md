# Sample 02 — Instruction Following Evaluation

## Task Type
AI Response Evaluation

## Evaluation Focus
- Instruction following
- Relevance
- Conciseness
- Format compliance

## User Prompt

> Give me exactly three tips for improving productivity. Each tip must be one sentence long.

## Response A

> 1. Create a daily task list and prioritize the most important work first.
> 2. Reduce distractions by turning off unnecessary notifications.
> 3. Take short breaks to maintain focus throughout the day.

## Response B

> Productivity can be improved in many different ways.
>
> First, you should create a list of tasks and decide which tasks are most important.
>
> Second, eliminate distractions such as social media and unnecessary notifications.
>
> Third, take breaks to refresh your mind.
>
> You can also improve productivity by sleeping well, exercising regularly, and keeping your workspace organized.

## Evaluation

### Response A

**Instruction Following:** Strong  
The response provides exactly three tips.

**Format Compliance:** Strong  
Each tip is written as one sentence.

**Relevance:** Strong  
All three tips directly address productivity.

**Conciseness:** Strong  
The answer is brief and focused.

### Response B

**Instruction Following:** Weak  
The response provides more than three tips.

**Format Compliance:** Weak  
The answer does not consistently follow the requested one-sentence-per-tip structure.

**Relevance:** Good  
The content is related to productivity.

**Conciseness:** Moderate  
The answer includes unnecessary additional information.

## Preferred Response

**Response A**

## Reasoning

Response A follows every explicit instruction in the prompt. Response B contains generally useful information, but it fails the requested constraints.

This example demonstrates that a response can contain good information while still receiving a lower evaluation if it does not follow the user's instructions.

## Suggested Improvement

Response B should be shortened to exactly three tips, with each tip written as a single sentence.
